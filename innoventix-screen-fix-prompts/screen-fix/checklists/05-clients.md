# Checklist: Clients (live domain)

[ ] New Client saves; appears once; survives reload
[ ] Client with no channel shows "Not connected" (not "Connected")
[ ] Platform shown matches what was entered
[ ] Count text ("Showing X of Y") is correct
[ ] Each filter (status, platform, mode, country, tag) works
[ ] Delete asks for confirmation and removes the client, or explains why it cannot
[ ] No stray empty box or blinking cursor on cards
[ ] Second account does not see this client
