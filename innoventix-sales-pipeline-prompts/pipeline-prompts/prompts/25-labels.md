# 25 - Labels (colored tags)

Add Trello-style labels.

- In the card detail sidebar, "Labels" opens a popover with the pipeline's labels as checkable rows (color swatch and name).
- Check or uncheck to attach or detach. Changes save immediately.
- "Create a new label" at the bottom: name (max 30 chars) and color picker from a palette. Creates the label for the pipeline.
- Rename and recolor existing labels, and delete a label (with confirmation that it removes it from all cards).
- Label chips on the card (prompt 18) show the full name on hover.
- Filters in prompt 31 use these labels.

Permissions: members can attach or detach; admin and owner can create, rename, recolor, and delete.
