# 36 - Multiple pipelines

Let each organization run several pipelines (for example "Enterprise Sales" and "Partners").

- The pipeline name in the header is a dropdown listing all pipelines, with "Create pipeline" and "Manage pipelines" at the bottom.
- Create pipeline: name, and whether to copy the stages from an existing pipeline or start blank with the default six stages.
- Manage pipelines: rename, set default, and delete (refused if it has deals, or offers to move them first).
- Remember the last viewed pipeline per user in the URL and in the user's profile preference, not in browser storage that the app doesn't already use.

Permissions: only admin and owner create or delete pipelines.
